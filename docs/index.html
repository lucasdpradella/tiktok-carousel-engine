Manual do Dinheiro

Engine pessoal de publicação automatizada · PRADEX · @pradella.lucas

Esta página existe pra hospedar os documentos legais exigidos pelo TikTok for Developers pra autorizar o app PRADEX a publicar carrosséis na conta TikTok @pradella.lucas via Content Posting API.

O app é de uso pessoal: gera e publica conteúdo do próprio dono em uma única conta TikTok, sem captar, processar ou redistribuir dados de outros usuários.

Termos de Uso Política de Privacidade

Authorize TikTok app

Este botão inicia o fluxo OAuth do Login Kit do TikTok pra autorizar o app PRADEX a publicar carrosséis na conta do dono (@pradella.lucas). Scopes solicitados: user.info.basic + video.upload.

Authorize TikTok app

Sobre o projeto

Manual do Dinheiro é uma série autoral de carrosséis sobre finanças comportamentais publicada por Lucas Pradella sob a marca PRADEX. A engine que gera os slides e o roteiro é mantida no repositório github.com/lucasdpradella/tiktok-carousel-engine.
