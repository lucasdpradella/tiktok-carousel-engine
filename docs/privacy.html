Política de Privacidade

tiktok-carousel-engine · Última atualização: 15 de maio de 2026

Resumo em uma linha: o App não coleta, não armazena e não compartilha nenhum dado pessoal de usuários do TikTok. Não há banco de dados de terceiros.

1. Natureza do App

"tiktok-carousel-engine" é um app de uso estritamente pessoal mantido por Lucas Pradella (lucasdpradella@gmail.com). Ele publica conteúdo próprio na conta TikTok do dono (@pradella.lucas) via Content Posting API. Não há interface pública. Não há cadastro de usuários. Não há atendimento a terceiros.

2. Dados que NÃO coletamos

O App não coleta nenhum dado pessoal de usuários do TikTok. Especificamente:

  • Não captura visualizações, curtidas, comentários, seguidores ou métricas de outras contas.
  • Não lê o feed, descoberta, busca, mensagens diretas ou notificações do TikTok.
  • Não acessa lista de seguidores, seguidos ou contatos do dono.
  • Não usa cookies de rastreamento. Não há analytics. Não há pixels de terceiros.

3. Dados que usamos (do próprio dono)

Pra funcionar, o App usa dois conjuntos de credenciais do próprio dono, armazenados como secrets criptografados na infraestrutura interna (GitHub Actions Secrets, Supabase Vault). Nenhum desses dados é compartilhado com terceiros.

  • Token OAuth do TikTok da conta @pradella.lucas — usado exclusivamente pra publicar carrosséis na própria conta.
  • API key do OpenAI — usada pra gerar o texto do roteiro de cada carrossel.
  • Credenciais do Supabase — usadas pra controlar a fila de temas (qual já foi publicado, qual é o próximo).

4. Armazenamento e retenção

O App armazena exclusivamente:

  • Lista de temas autorais a serem publicados (texto curto, escrito pelo dono).
  • Status de publicação de cada tema (publicado / pendente, com timestamp).
  • Imagens PNG geradas pra cada post, mantidas como artifact do GitHub Actions por até 14 dias após geração — depois são automaticamente apagadas.

Nenhum desses dados é pessoal de terceiros. São dados do próprio dono e do conteúdo autoral publicado.

5. Compartilhamento com terceiros

O App se comunica com três serviços externos, todos contratados pelo dono e usados em modo pessoal:

  • TikTok — pra publicar o carrossel autoral.
  • OpenAI — pra gerar o texto do roteiro.
  • Supabase e GitHub — pra hospedar a fila de temas e rodar o agendamento.

Em nenhum desses casos há transmissão de dados pessoais de terceiros, porque o App nunca coleta esse tipo de dado.

6. Direitos do titular

Como o App não coleta dados pessoais de usuários, não há dados de terceiros pra acessar, corrigir ou excluir. Mesmo assim, qualquer pessoa que se sentir afetada pode entrar em contato pra esclarecimentos: lucasdpradella@gmail.com.

7. Alterações desta Política

Esta Política pode ser atualizada sem aviso prévio. A versão vigente é sempre a publicada neste endereço. Versões anteriores ficam preservadas no histórico do repositório público.

8. Conformidade

Este App busca operar em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei 13.709/2018) do Brasil e com os princípios do GDPR europeu, sendo que sua natureza de uso pessoal sem coleta de dados de terceiros minimiza o escopo de aplicação dessas regulações.
