Como funciona

Esta página é o endpoint redirect_uri do Login Kit do TikTok. Depois do dono do app autorizar a aplicação no TikTok, o TikTok redireciona pra cá com o parâmetro code na URL. O dono copia esse code e troca por um access_token de longa duração via chamada server-side (uma vez só — depois o token vive como GitHub Secret).

Esta página não envia nada pra lugar nenhum. Só exibe o code recebido pra cópia manual. Nenhum dado sai do seu navegador.
